# WAMR ESP-IDF Source Overrides

Full-file replacements live here only when the implementation is intentionally
project-owned and cannot be expressed as a focused upstream patch. CMake swaps
the matching upstream source into the WAMR target without modifying the
submodule.

## 中文

只有明确由项目维护、且不适合表达为小型上游补丁的完整替代实现才放在这里。
CMake 会在 WAMR target 中替换对应源码，不会修改子模块工作区。
