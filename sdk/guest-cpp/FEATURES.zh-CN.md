# C++26 工具链与特性支持

SDK 要求 C++26 编译模式。当前锁定 WASI SDK 34，实际编译器为 Clang 23.1.0，
libc++ 版本宏为 230100；目标为 `wasm32-wasip1`。编译选项与实际特性分开验收，
不能据此宣称完整支持 C++26。

CMake 在配置阶段编译真实代码，验证 C++26 模式、显式对象参数、包索引、
`std::expected`、`std::span` 和协程头文件；完整任务测试再验证协程行为。
支持 `cxx_std_26` 时使用该编译特性，否则检测并显式传递 `-std=c++2c`。
公共头文件再次检查模式及关键特性宏，不允许应用静默退回 C++23。

| 能力 | SDK 使用方式 | 验证和边界 |
| --- | --- | --- |
| C++26 模式 | 所有 SDK 和应用 C++ 源文件 | 当前 `__cplusplus=202400L`，不是完整标准支持的声明 |
| 显式对象参数 | 链式 UI 属性保持左右值类别 | 配置编译与主机类型/行为测试 |
| 带说明的 delete（C++26） | Transport 稳定地址、资源/Task 单一所有者的编译诊断 | 原生及 WASI 真实编译，配置阶段和宏检查 |
| if consteval | 重叠安全字节编码：编译期循环、运行期 memmove | constexpr 断言、运行期重叠输入和 sanitizer |
| 包索引 | 子视图类型访问和容量汇总 | 配置编译、编译期断言、真实 UI 构建 |
| expected/span/array/tuple/charconv | 错误、借用、有界存储、组合和格式化 | 模块测试与实际 Wasm/AOT；容器使用不等于不分配 |
| 协程 | 有界帧池、作用域任务、请求结果 | 取消、耗尽、晚到结果和重复使用测试 |
| inplace_vector/function_ref | 可选，当前 Guest 不依赖 | 配置单独编译探测；不可用时不影响必需接口 |
| 反射/template for | 本期不依赖 | 不能成为完成交付的前提 |
| 线程、桌面网络/文件系统接口 | 不作为普通 SDK 接口 | 使用 PXA 的服务、权限和事件模型 |

当前 WASI libc++ 的 `<version>` 没有声明 `inplace_vector` 和 `function_ref`。
CMake 会进一步编译探测并报告结果。不要因为主机标准库提供这些设施，就把它们
加入 Guest 必需路径。2026-10-11 原生测试环境为 Clang 23.1.1/libstdc++ 16，主机测试
会按实际可用性验证这两项可选设施；主机结果不能替代 WASI 验证。

原生测试默认使用 `clang++`，也可设置 `CXX` 为支持上述必需特性的编译器：

```sh
bash tools/package/test_guest_cpp.sh
```

WASI 初始化、stdio、时钟与随机源受到实际导入和清单能力约束。libc++ 链接可以
引入额外 WASI 导入，打包时检查全部导入；PXA SDK 本身直接使用 `pxa_submit` 和
`pxa_io`，不意味着整个 Wasm 只有这两个导入。异常和 RTTI 默认关闭，不能依赖
抛异常处理容器耗尽；借用式回调不能作为页面持有的长期 lambda。

工具链升级必须锁定发行包与摘要，重新运行特性探测、主机测试、三目标
Wasm/AOT、模拟器和可用实机验证。语言模式切换和实现优化分别建立对照，
不能用语法更新代替性能数据。
