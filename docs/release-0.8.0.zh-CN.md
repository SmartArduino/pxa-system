# PXA 0.8.0

PXA、Guest C/C++ SDK、DevKit、桌面模拟器及 PXADB 使用同一发行号。
Core 保持 2.1，AOT ABI 保持 `wamr-pxa-aot-v6-core-1`；应用的运行兼容性仍按
其声明的服务、功能位、容器及执行目标检查，不要求应用 SDK 与设备发行号相等。

## 新增与修复

- UI 升至 0.10，增加有界的系统字体字形读取。C 的 `pxa_font.h`、C++ 的
  `pxa/font.hpp` 可读取基线、字形度量和覆盖位图，不向应用暴露系统字体路径或指针。
  单字形最多 3072 字节；不影响未调用该接口的游戏渲染路径。
- 修复 ESP 文件系统目录操作重入导致的 POSIX 槽锁死。
- 安装预装应用的签名覆盖版本时保留原应用私有数据，避免覆盖后丢失进度。
- 已提交应用启动时避免重复进行整个包的文件校验；安装和事务恢复仍执行完整验证。
- 浏览器运行时已有独立的 0.7.7 发行：修复透明 UI 合成与文字覆盖，接入原生音频采集、
  网络和体感，增加磁力计及绝对朝向。网络使用浏览器原生请求，不经商城服务器转发，
  仍受 HTTPS、CORS 及浏览器权限限制。运行时独立版本不因本次原生 SDK 发布而改名。
- AI 工具支持批量构建和更清晰的资源归属，本版配套 Agent Kit 0.4.3。

旧 UI 0.9 应用继续使用原有命令；使用新字体接口的应用需声明 UI 0.10 和对应功能位，
旧固件不能使用该新功能。历史 SDK、应用包和已发布资产不覆盖或重新编号。
