# 可安装输入法

输入法是签名 PXA 包中的独立 Service Component，依赖可选的 `ime 0.1`（service 22）并声明 `provider` feature。系统设置枚举安装元数据、由用户选择；枚举不会执行 Guest。真正激活时再次验证签名和完整文件清单，并选择当前架构 AOT 或可移植 Wasm。普通应用继续使用 `ui::TextInput`，不依赖输入法 SDK。

pxa-apps 提供 `pinyin-ime`（词句解码）和 `pinyin-ime-lite`（小型拼音单字表）两种可独立安装的 Provider。两者共用 Host 手机键盘、设置和同一编译期编辑流程，不复制 UI 或增加 ABI。轻量版不携带 `dict_pinyin.dat`、统计解码器和词库缓存，启动不需要词典能力；其 6,749 个不同汉字/7,292 个读音条目的约 19 KiB 不可变字表计入 Guest 线性内存。连续拼音逐字选择，分词可消除拼音边界歧义，没有智能整词、整句候选。无新增默认 Host 缓存，未安装/未打开时不运行该 Guest。受限设备可构建单架构 AOT-only 包以省去 Wasm 回退和其他架构；这减少安装与验证的文件量，不取消签名校验。

系统拥有编辑器、焦点、光标、密码处理、键盘布局、字体和合成层。输入法只接收按键与自己的预编辑状态，输出预编辑、候选和一次编辑事务；它不会收到 LVGL 指针、前台应用的存储能力、周围正文或密码。预编辑独立显示，选词后才提交正文。包的其他 UI/FS/网络权限不会自动授予输入法服务；当前并发加载器仅接受 Core、WASI 和 IME 依赖。

## 生命周期和内存

每个焦点/光标会话使用单调递增的 64 位标识。输入有单调序号，回复只能按发送顺序消费一次；旧会话、重放或其他 Component 的回复被拒绝。切换输入框、外部改写正文、关闭或应用后台切换会废弃预编辑。声明式 UI 对已接受文本的重复设置不会取消会话。

ESP 产品 Host 在已有应用运行时复用其 runtime/engine，用独立 coordinator 管理输入法；原生系统编辑器可按需启动只含输入法的 runtime。英文或密码不请求中文 Provider；中文加载中切换英文取消验证，已加载时则卸载 Guest 和词典。关闭后释放 Guest、词典表及图元，输入法注册工作区在 runtime 结束后释放，避免悬空服务回调。桌面产品 Runner 支持前台 PXA 应用中的独立输入法；没有 PXA Runner 的桌面原生系统页面目前仍使用内置输入法。

Host 不创建第二张帧缓冲、深度缓冲或字形图集。词典通过组件私有只读文件能力加载；引擎直接读入最终解码表，不额外缓存整份原始词典。候选是有界窗口，Host 根据字形宽度分页；回复仅在回调期间借用 Guest 内存。UI 保留当前页的最小文本副本。

UI 有 16 个短按键的有界队列，一次发送一个动作，`WOULD_BLOCK` 会重试。首次 RESET 确认前保留提前输入的中文按键；首次启动最多等待 10 秒，后续动作 3 秒无回复切换系统键盘。引擎回复前禁用旧候选；队列满时暂停按键输入，不无限分配。英文及密码由 Host 直接编辑，不等待词库；加载期间的数字/符号可在没有更早拼音动作时直接编辑，避免越过之前输入。关闭时暂停定时器；打开后的空闲检查每 80 ms 仅比较光标和编辑器几何，补足 LVGL 没有公开程序移动光标事件的情况，不轮询 Guest。Fault 只终止输入法，前台应用继续运行；ESP watchdog 按 Component 识别超时，避免将输入法归到前台应用的无响应弹窗。

产品 Host 等待键盘的首次 `DRAW_POST_END` 后才开始加载，绘制回调只通知 owner，不进入 Guest。可选 POSIX 验证任务分别执行元数据读取、签名认证、完整目录清单检查和分块文件摘要；每次摘要处理最多 16 KiB，复用安装器的 4 KiB 缓冲，不创建加载线程或常驻缓存。结果在所有步骤完成前不可执行。关闭、目标删除、切换英文会取消任务；ESP 在验证到激活期间持有包事务租约，安装忙时非阻塞重试，应用切换先取消加载再查询包。关闭后的 owner 快速路径不锁 LVGL、不轮询空 Guest。

ESP 校验和初始化不持有 LVGL 锁，前台 Guest 可在验证步骤之间继续处理事件。签名认证、目录枚举及最终 WAMR/解码器初始化仍是同步步骤，16 KiB 预算不约束这些阶段的耗时；当前真机最长约 0.8 秒，不能宣称完全无停顿。桌面 Runner 同样在步骤之间处理 UI/前台事件，但与 UI 共用线程，同步阶段仍会阻塞 UI。首次绘制、Provider 加载和首次 RESET 确认分别计时，不将键盘已经绘制等同于词库就绪。

解码表加载后 Guest 立即关闭词典能力。Host 使用文件描述符直接读取，避免 ESP Newlib 无缓冲 `fread` 把大块读取拆成单字节 VFS 调用。参考包的线性内存上限为 4 MiB，未固定预分配；实测线性内存按需增长到约 1.2 MiB。Host 的可重入 widget 回调只能排队，不能在输入法 import 回调中再次进入另一个 Guest。

## 紧凑布局

手机式键盘分为主键区与固定底栏。中文九键三行四列：标点/2 ABC/3 DEF/删除，4 GHI/5 JKL/6 MNO/分词，7 PQRS/8 TUV/9 WXYZ/回车。全键始终使用完整 QWERTY；中文保留分词，英文 Shift 单次大写、快速双击锁定、再次点击取消。英文默认全键，也可在工具页主动选择九键多击输入（650 ms 确认）；九键长按直接输入数字。数字四行，符号两页。每个主面板只有一个删除、回车和收起入口。

固定底栏为符号、123、语言、宽空格、收起。语言显示当前「中」或「EN」，点击切换；数字/符号面板的当前入口改为「返回」。齿轮打开布局/语言工具页，不隐藏高频切换操作；已选选项高亮，密码禁用中文和九键。

空闲时仅一行工具栏，不显示空的预编辑/候选框。组合输入时上排显示当前预编辑及九键其他读音，下排是候选词；选中的读音只显示一次。两排分别左右滑动，松手不会误选词或下方按键。箭头展开候选网格，替换主键区；「键盘」恢复输入并保留组合。复用同一 candidate matrix 及当前页文本，不创建额外弹窗。分页只保留最近 32 个返回点，超过后滚动历史，向前不受限制；更早位置可回首页。

空格确认首候选，空闲时插入空格；长按后左右拖动移动原光标，不插入空格。回车先确认组合；没有组合时，多行编辑器插入换行，单行完成并触发 READY。收起只隐藏键盘，不触发表单提交。语言/布局切换按顺序确认已有组合与排队输入，避免丢字；外部光标移动或正文改写仍取消旧组合。九键分词锁定当前完整读音，选中半句后恢复剩余九键状态。

布局按字体、DPI、安全边距、圆形弦宽及四个独立圆角计算实际区域。圆屏/圆角屏逐行扩大键区，绘制和触摸区域一致；组合栏向上展开，尽量保持主按键位置。大屏居中并限制宽度，通常采用 60% 高度预算，约束冲突时允许提高占比。极窄屏完整 QWERTY 触摸目标较小，自动布局默认选九键。

优先复用系统字号，必要时按需打开最多一个较小的大陆黑体 face。拉丁字符和图标优先使用固件已编译的抗锯齿位图字体，中文保留原黑体 fallback，不新建 face 或缓存。12 px 固定标签使用随适配器发布的 39 个字形（含中点）的大陆黑体 A8 位图（5,532 B，只读映射），普通候选继续回退产品字库；大字号仍用产品字体。按键表只读静态存放，不在每个实例复制；共享按键样式，无新增帧缓冲、图集或线程。 已加载中文时，切到英文先请求运行时 owner 释放 Provider，再按 generation 确认并构造完整英文键表，避免词库与新键表的瞬时重叠；尚未启动中文时英文仍可直接编辑。

Host 优先临时滚动已有容器，使原编辑器当前光标行可见，关闭或切换焦点时恢复滚动位置。固定、浮动或过高编辑器使用键盘内的当前行辅助区，点击文字或左右箭头移动原编辑器光标；它按需保存至多 257 字节 UTF-8 窗口，没有全文复制和第二套编辑状态，密码只显示掩码。辅助区保持到本次关闭，避免滚动时显隐反馈。容器或目标删除会清除借用引用。没有新增 Window 键盘遮挡 Insets ABI，不改变应用的尺寸、内边距、安全边距或整个页面布局。

ESP PXADB 提供 `IME` 查询注册/当前选择及输入处理时间、`IME select builtin|<publisher:app-id>` 选择。`TIMING` 追加 `provider_load_us`、`keyboard_drawn`、`first_draw_ms`、`candidates_ready`、`candidates_ready_ms`、`provider_steps`、`provider_step_max_us`，区分焦点到首次键盘绘制、Provider 校验/加载、焦点到首次 RESET 回复。输入统计从 Host 按键入队到 Provider 回调，包括排队与解码/提交；本地英文不计为 Provider 动作。首次绘制不包含 LCD 扫描，输入处理时间不包含 LVGL 绘制，均不能作为完整触摸延迟。设备空间不足时 `PACKAGE archive <identity>` 仅移除包文件，保留私有数据、授权和启用策略；重新安装同一身份的签名包可恢复应用。普通 `uninstall` 仍删除私有数据。

## 系统设置

系统设置提供独立「输入法」页面（使用正常返回导航与滚动列表）：选择默认输入法、自动/全键/九键布局和默认中文/英文，并链接到应用管理进行更新、禁用或卸载。页面进入时替换设置主页，不保留背景遮罩；应用管理返回到输入法页。选择成功后页面立即显示选中标记；保存失败回滚选项并提示。ESP 以 NVS、桌面产品以版本化原子文件持久化，设置在下一次聚焦时生效，避免打断当前预编辑。英文默认全键并本地编辑，可主动选九键；密码始终全键并本地编辑；密码不能启用中文 Provider。布局/语言是 Host 配置，不增加 Guest ABI 或词库缓存。原生内置键盘也遵循偏好。

## 协议 0.1

整数均为小端；字符串 UTF-8，无 NUL。所有保留位/字段为零。经 Core 2 `pxa_call` 控制通道和可靠事件队列传输，无新增导入。

`INPUT (0x8001)` Host → Guest，token 0，24 字节头：

| 偏移 | 类型 | 含义 |
|---|---|---|
| 0 | u64 | 非零 session |
| 8 | u32 | 非零 sequence |
| 12 | u16 | action |
| 14 | u16 | flags：bit 0 sensitive（产品不向外部引擎转发密码） |
| 16 | u8 | layout：0 全键、1 九键 |
| 17 | u8 | language：0 中文、1 英文 |
| 18 | u16 | reserved |
| 20 | u32 | value |
| 24 | bytes | text，仅 TEXT 可以携带 |

Action：RESET=1、TEXT=2、BACKSPACE=3、CONFIRM=4、CHOOSE=5、PAGE=6、CHOOSE_PINYIN=7。TEXT value 0 表示拼音/英文键，1 表示数字或符号面板的字面输入；中文引擎先提交预编辑再插入字面值。CONFIRM value 0 为空格/首候选，1 为提交并完成；CHOOSE/PAGE 为候选绝对索引，CHOOSE_PINYIN 为拼音列表索引。RESET/BACKSPACE value 0。Host 的首次输入是 RESET，序号 1；每个输入必须回复一帧，即使是空状态。

`PRESENT (1)` Guest → Host，token 0，32 字节头：

| 偏移 | 类型 | 含义 |
|---|---|---|
| 0 | u64 | session |
| 8 | u32 | 已处理的 sequence |
| 12 | u16 | flags：bit 0 后续候选、bit 1 完成编辑 |
| 14 | u16 | edit：NONE=0、INSERT=1、BACKSPACE=2、SUBMIT=3、CLEAR=4 |
| 16 | u32 | 候选窗口起点 |
| 20 | u16 | preedit 字节数 |
| 22 | u16 | commit 字节数；仅 INSERT 非空 |
| 24 | u16 | 候选条数 |
| 26 | u16 | 拼音条数 |
| 28 | u32 | reserved |
| 32 | bytes | preedit、commit、候选记录、拼音记录 |

每个列表记录为 `length:u16 + 非空 UTF-8`。编辑事务每帧最多一次；字符串与列表总量受 Core 控制消息 4076 字节载荷上限约束，不依赖固定词典大小。参考引擎使用 2048 字节回复、最多 12 个候选和 32 个拼音。

可选启动记录 `0x800d`：16 字节 `handle:u64 + size:u64`。当前 POSIX/VFS 加载器识别签名清单中的 `assets/dict_pinyin.dat`，提供组件私有、不可写、不可跨组件使用的文件能力；READ=1，SEEK_ABSOLUTE=3（8 字节绝对位置，成功返回 0）。无此资产的其他引擎可以自行生成候选，不必使用该记录。

## C++ Provider

可选头 `<pxa/ime.hpp>` 提供 `Input`、`decode_input(Event)` 和 `Frame`。`Frame` 使用调用者提供的 `std::span<std::byte>`，本身不分配；引擎可按需使用 `std::string`，协议按字节长度编码。普通 TextInput 的文案长度、字体和正文状态仍由应用管理。

```cpp
std::array<std::byte, 2048> wire;
auto input = pxa::ime::decode_input(event);
if (!input) return std::unexpected(input.error());
pxa::ime::Frame frame(wire, *input);
if (auto r = frame.composition("ni"); !r) return r;
if (auto r = frame.candidate("你"); !r) return r;
return frame.present(ctx.transport());
```

真实引擎应处理全部动作和每次会话重置。焦点变化可能使已经排队的回复得到 `bad_state`/`denied`；应丢弃该回复，而非让整个 Provider 崩溃。参考实现位于独立 pxa-apps 仓库的 `pinyin-ime`。
