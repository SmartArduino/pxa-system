# PXA 0.10.0 与 Agent Kit 0.6.0

本版改进应用布局、真实 UI 验收与 AI 开发循环，并提供精简的 Linux/Windows 工具分发。

## 布局与系统界面

物理安全区、可见系统栏和仍工作的系统手势分别报告。SafeArea 默认不因侧边返回
手势整体右移；冲突的边缘控件可单独避让。背景可铺满，状态栏隐藏后释放固定顶部
空间，物理圆角和缺口继续生效。系统栏 RGBA 背景及图标明暗样式参与实际绘制；
返回系统主页恢复系统主题。Wi-Fi 图标随实际信号分级，RSSI 查询缓存 5 秒。

声明式 UI 修复 Button 修饰器顺序及文字垂直居中、Progress 零值轨道对比和 When
分支布局；挂载/更新失败通过日志和错误回调报告。Window 0.5 提供方向请求及
当前角度、原生尺寸、支持角度查询，按设备实际支持适配；方屏不靠宽高猜测阅读方向。

## 开发与验收

真实 Host UI 节点、文字、状态与像素矩形可供 inspect、tap-node、expect、wait-for
使用，密码内容隐藏。验收构建一次，在隔离存档和调试接口下并行运行所选屏幕，
记录语义断言、实际几何和原始截图。拼图只用于查看；商城使用检查合格的真实矩形
原图。`--no-build` 校验源码/依赖、锁、参数及包摘要，旧 SDK 不会被默默改写。

Agent Kit 独立携带设备客户端。安装前按真实包与设备比较 Core、服务/特性、CPU、
AOT ABI 和容器能力，缺失信息保留 unknown。`firmware status` 只读版本及签名清单。
工作区迁移与项目 `sdk update` 分开，保留签名身份、存档和审计历史。

计时器/计数器配方提供可运行骨架及语义旅程；AI 仍须实际构建、操作并检查截图。
设备连接指引包含参考 UI 的开发者解锁和 PXADB 开启步骤。像素游戏建议、素材准备、
浏览器商城授权及真实截图流程继续由随包技能和网站 AI 入口提供。

## 分发、清理和兼容

默认工具链针对 PXA 使用的 wasm32-wasip1，保留 C/C++、链接、归档与检查工具和
必要许可证；维护者可选择完整上游工具。已安装 SDK 不会被原地裁剪。成功安装后
可释放 SDK 下载缓存，也可显式保留归档供离线修复。项目 clean 与构建共用锁，
保留当前输出、源码、项目锁、密钥及存档。

原生 **Host C ABI 升为 2**：UI 环境/配置和 Window 快照结构扩展，原生 Host
集成者须重新编译并使用同一发行版的库。此编号独立于 Guest Core/AOT；Guest
Core 仍为 2.1，AOT 配方保持不变，旧包按其服务需求协商。使用新增服务功能需显式
声明并核对目标 Host，发行号不同不直接等于不兼容。

Linux x64 原生包要求 glibc 2.39+；Windows x64 包声明实际 Windows/Wine 验证范围。
Wine 验证不能替代真实 Windows 的窗口、音频和 COM 设备验收。其他平台使用支持的
容器开发流程，模拟器结果不能替代设备帧率、内存、传感器和操作手感实测。
