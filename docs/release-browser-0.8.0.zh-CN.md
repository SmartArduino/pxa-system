# PXA Browser Host 0.8.0（实验版）

本版基于 PXA 0.8.0、Core 2.1 构建，继续使用标准 C/C++ Guest SDK 和 Wasm。浏览器宿主单独发行，不覆盖已发布的 SDK、设备固件或历史 Browser Host。

- 接入 UI 0.10 的系统字体字形读取，返回行高、基线、字形度量及有界 A8 覆盖位图。尺寸为 8–48 像素，单字形最多 3072 字节；不提供字体路径或原生指针。
- 能力清单同步声明 UI 0.10 和字体功能位，让符合声明的应用可通过网页兼容性筛选。已有 0.7.x 普通 UI、Surface、GameRender 和主循环应用继续使用原协议。
- 增加真实 Guest 字形读取回归用例，覆盖可见字形、空格和参数边界。

## 使用与升级

官网和商城播放器使用同一版本运行时。保存作品进度后刷新页面，再启动作品即可切换版本；更新运行时不会主动删除浏览器存档。部署保留旧版本地址，已打开的页面继续读取原版本。

浏览器只运行 Wasm，不能执行芯片 AOT。发布兼顾网页与真机的包时保留主组件 Wasm，并声明实际需要的服务、功能位及权限。Core 2.1 主循环依赖 WebAssembly JSPI；原生网络仍受 HTTPS、CORS 和浏览器权限限制。

Surface 使用固定的 Host 影子缓冲和帧提交复制。网页完成绘制的更新率不能代替设备 LCD 的实测帧率。字体来自运行浏览器的系统，与设备字体或应用自带像素字体可能不同。
